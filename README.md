# TIS Education

TIS Education is a modern React-based school website built for Tulas International School. It provides a polished landing page experience highlighting academics, co-curricular excellence, achievements, testimonials, admissions, and contact information.

## Features

- Responsive, visually rich landing page
- Hero section with layered artwork and motion effects
- School navigation with dropdown menus
- Student feedback, rankings, and awards sections
- Collaboration and review highlights
- Inquiry/contact call-to-action components
- WhatsApp and chatbot floating widgets

## Stack

- React
- Vite
- CSS
- React Icons

## Run locally

```bash
cd client
npm install
npm run dev
```

Then open the local URL shown in the terminal.

## Build

```bash
npm run build
```
